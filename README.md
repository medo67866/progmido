# progmido — Mohamed Hassan Portfolio

A modern, responsive static portfolio for Mohamed Hassan, Web Developer & Digital Solutions.

## Features
- Responsive Bootstrap 5 layout
- Modern dark/light section system inspired by the ROYALRING visual direction
- Personal portrait
- Services and skills
- Featured ROYALRING case study
- WhatsApp direct-contact buttons
- Email, GitHub and LinkedIn links
- Scroll progress and reveal animations
- GitHub Pages friendly — no backend or database required

## Run locally
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for the Pages URL to become available.
